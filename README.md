# Site de présentation du jeu Rust <img width="25 height="25" alt="logo Rust" src="https://github.com/user-attachments/assets/5eea05ef-7978-4a19-9a75-9c84cd89ef19" />
Ce site a pour objectif de présenter un jeu du nom de Rust.

## Contexte 
Ce site a été développé au cours d'un projet durant ma première générale en NSI (numérique et sciences informatique). Le but était de réalisé un petit site pour présenter un de nos jeux favoris. J'ai donc choisis le jeu Rust. Ce jeu est un jeu de survie en multijoueur.

## Fonctionnalités  
- Une première page d'accueil avec une vidéo en arrière plan et le menu en haut.
- Une page 'BUT DU JEU' pour présenter en globalité le jeu.
- Une page 'ARMES' pour montrer toutes les armes présentent dans le jeu.
- Une page 'SITE OFFICIEL' qui renvoie directement au site officiel du jeu.
- Une page 'ACHETER LE JEU' qui renvoie à la page Steam du jeu pour pouvoir l'acheter.

## Langages utilisés
Les langages utilisés sont :
- HTML
- CSS
